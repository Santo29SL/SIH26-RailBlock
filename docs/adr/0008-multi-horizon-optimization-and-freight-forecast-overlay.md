# Multi-Horizon Constraint Optimization and Goods Trains Forecast Corridor Occupancy Overlay

We extend the Google OR-Tools CP-SAT optimization pipeline to support multi-horizon planning (24-hour tactical, 7-day weekly rolling, and 30-day monthly corridor schedules via `POST /api/v1/optimizer/run?horizon_days=7|30`) coupled with a **Goods Trains Forecast Overlay** (`movement_type="FORECAST_FREIGHT"`).

Indian Railways freight rakes operate on unscheduled, non-timetabled paths generated by the Control Office Application (COA). If corridor gap extraction only considers published passenger timetables, monthly 30-day schedules generate artificial, over-optimistic gaps where heavy freight rakes actually run. By injecting anticipated goods-train paths from the COA forecast as legitimate corridor occupancy with mandatory $\ge 15\text{ min}$ safety headways, the solver ensures that long-range maintenance possessions respect true line capacity and never conflict with future freight demand.
