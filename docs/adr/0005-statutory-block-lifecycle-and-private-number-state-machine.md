# Statutory Block Lifecycle and Private Number Exchange State Machine

We enforce a strict finite state machine for maintenance blocks under Indian Railways General and Subsidiary Rules (G&SR):
1. `PROPOSED`: Generated by the AI optimizer or controller request.
2. `APPROVED`: Verified by division control; corridor slots locked.
3. `ACTIVE`: Officially granted by the Station Master; requires a validated Station Master **Private Number (PN)** and field engineer token for Disconnection Notice (Form T/351).
4. `COMPLETED`: Officially cancelled and track restored; requires a Reconnection Notice (Form T/351-B), clearance PN, and mandatory Temporary Speed Restriction (TSR) entry.

Treating block statuses as freeform editable strings allows bypassing statutory railway safety procedures. Enforcing state transitions with cryptographic/numeric Private Number audit fields guarantees regulatory compliance.
